PROJETO AVALIATIVO – ENTREGA 1
TaskClass – Organização de Trabalhos Escolares
1. Ideia do projeto
Minha ideia é desenvolver um aplicativo chamado TaskClass, voltado para a organização de trabalhos escolares. Pensei nesse projeto porque, principalmente em trabalhos em grupo, muitas vezes é difícil organizar o que cada pessoa precisa fazer, quem ficou responsável por cada tarefa, quais atividades já foram concluídas e quais ainda estão pendentes. A proposta do TaskClass é reunir essas informações em um único aplicativo, deixando a organização dos trabalhos mais simples e evitando que informações importantes fiquem perdidas em conversas ou mensagens.
2. Problema identificado
O problema que quero ajudar a resolver é a dificuldade de organização dos estudantes durante trabalhos e projetos escolares, principalmente quando existem várias tarefas, diferentes responsáveis e prazos para cumprir. Quando a organização é feita somente por mensagens, anotações ou conversas entre os integrantes, pode acontecer de uma tarefa ser esquecida, duas pessoas fazerem a mesma coisa ou alguém não saber exatamente pelo que ficou responsável. Também pode ser difícil acompanhar o andamento geral do trabalho.
3. Público afetado 
O público principal do TaskClass são estudantes que realizam trabalhos e projetos escolares, especialmente atividades feitas em grupo. O aplicativo poderá ajudar tanto na organização das tarefas de cada integrante quanto na visualização do andamento do trabalho como um todo.
4. Justificativa
Escolhi esse problema porque trabalhos em grupo fazem parte da rotina escolar e dependem bastante de organização. Quando as tarefas não são bem divididas ou os prazos não ficam claros, o grupo pode ter dificuldades para concluir o trabalho corretamente e dentro do prazo. Por isso, acredito que um aplicativo que concentre trabalhos, tarefas, responsáveis, prazos e status das atividades pode tornar esse processo mais organizado e facilitar a comunicação entre os integrantes.
5. Proposta de solução
Minha proposta é criar o TaskClass como uma aplicação mobile em que os estudantes possam visualizar seus trabalhos e acompanhar as tarefas relacionadas a cada um deles. Cada trabalho poderá ter informações como matéria, tema e prazo. Dentro dele, poderão existir diferentes tarefas, mostrando o responsável e o status da atividade, por exemplo: Pendente, Em andamento ou Concluída. Nas próximas etapas, a ideia é evoluir o aplicativo para permitir cadastro e login de usuários, criação, edição e exclusão de trabalhos e tarefas, armazenamento das informações no banco de dados e controle das ações de acordo com o nível de cada usuário.
6. Tipos de usuário e permissões
O sistema terá inicialmente dois tipos de usuário: Administrador do grupo e Membro.
O Administrador do grupo terá mais permissões e, na versão completa do projeto, poderá criar trabalhos, cadastrar tarefas, editar informações, excluir registros e definir responsáveis. O Membro poderá visualizar os trabalhos e tarefas do grupo e acompanhar as atividades que foram atribuídas a ele. As permissões serão desenvolvidas e aprimoradas nas próximas etapas do projeto.
7. Principais funcionalidades previstas
As principais funcionalidades planejadas para o TaskClass são: cadastro e login de usuários; visualização e organização de trabalhos escolares; criação de tarefas; definição de responsáveis; definição de prazos; acompanhamento do status das tarefas; edição e exclusão de informações; perfil do usuário; e controle de permissões de acordo com o tipo de usuário.
8. Telas previstas
Na primeira versão, o aplicativo terá uma tela inicial apresentando o TaskClass, uma tela com a lista de trabalhos, uma tela de detalhes do trabalho e uma tela de perfil. Na tela de trabalhos, o usuário poderá visualizar os trabalhos cadastrados. Ao selecionar um deles, será direcionado para a tela de detalhes, onde poderá ver informações como tema, prazo, tarefas, responsáveis e o andamento de cada atividade. A tela de perfil apresentará informações básicas do usuário e servirá como base para as funções de cadastro, login e níveis de acesso que serão implementadas posteriormente.
9. Fluxo inicial de navegação
O fluxo inicial começa na tela de início do TaskClass. A partir dela, o usuário poderá acessar a lista de trabalhos. Na lista, poderá selecionar um trabalho para visualizar seus detalhes ou acessar a tela de perfil. Também será possível retornar às telas anteriores pela navegação do aplicativo. Dessa forma, a primeira entrega já apresenta uma versão navegável e demonstra como as principais telas do sistema estarão relacionadas.
10. Desenvolvimento da primeira entrega
Para esta primeira etapa, estou desenvolvendo o projeto em React Native com Expo e utilizando React Navigation para fazer a navegação entre as telas. A estrutura inicial do aplicativo está sendo organizada em pastas para separar as telas e permitir que o projeto continue evoluindo nas próximas entregas. Nesta etapa, os dados exibidos no aplicativo são iniciais e servem para demonstrar a proposta, a interface e a navegação. A integração com API e banco de dados será feita posteriormente, conforme a evolução do projeto. O projeto também será mantido em um repositório Git, com commits e atualizações enviados ao repositório para registrar a evolução do desenvolvimento.
11. Objetivo final
Meu objetivo com o TaskClass é criar uma aplicação que realmente ajude estudantes a organizar trabalhos escolares de forma mais clara. Ao final do projeto, pretendo ter um sistema funcional em que usuários possam acessar suas contas, organizar trabalhos e tarefas e utilizar diferentes permissões de acordo com seu tipo de usuário.
